Simple Python Calculator

My first Python project — a command-line calculator built using Python.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Remainder (%)
- Power (**)
- Division-by-zero handling
- Repeated calculations using a while loop
- Exit option

Technologies Used

- Python 3
- Visual Studio Code

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

py calculator.py

What I Learned

- Variables and data types
- User input and output
- Conditional statements
- Arithmetic operators
- While loops
- Break statements
- Basic error handling for division by zero
